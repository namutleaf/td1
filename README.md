# td1 — 미로 영웅 TD (가제)

배치로 미로를 짜고, 영웅을 직접 조종해 싸우는 로그라이크 타워디펜스 **프로토타입**.

## 실행

빌드 과정 없음. `index.html`을 브라우저로 열면 바로 플레이됩니다.

```bash
# 또는 로컬 서버로
python3 -m http.server 8000   # → http://localhost:8000
```

## 조작

| 입력 | 동작 |
|---|---|
| WASD / 방향키 | 영웅 이동 |
| 우클릭 | 해당 지점으로 영웅 이동(자동 길찾기) |
| Space | 영웅 스킬(회오리) |
| 1~4 | 벽 / 화살탑 / 대포탑 / 냉기탑 선택 |
| 좌클릭 | 설치, 또는 건물 선택 |
| U / X | 선택한 건물 강화 / 판매 |
| Enter | 웨이브 시작 |
| F / P / Esc | 배속 / 일시정지 / 선택 취소 |

## 구조

```
index.html      화면 레이아웃
style.css       UI 스타일
src/config.js   밸런스 데이터 (타워·적·영웅·유물·웨이브)
src/board.js    격자 맵, 적 길찾기(흐름장 BFS), 영웅 길찾기
src/game.js     게임 루프, 전투, 아이템, 렌더링, 입력, UI
docs/GDD.md     기획 초안 (시스템, 로드맵, 수익 모델 검토)
```
