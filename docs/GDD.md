# 미로 영웅 TD (가제) — 게임 기획 초안 v0.1

> 테마는 미정. 지금은 **규칙과 재미 검증**이 목적이며, 비주얼은 "한눈에 읽히는" 도형·색 위주로 만든다.

## 1. 한 줄 요약

**내가 짠 미로 위에서, 내가 직접 조종하는 영웅이 싸우는 로그라이크 타워디펜스.**

## 2. 핵심 기둥 (Design Pillars)

| 기둥 | 설명 | 프로토타입 반영 |
|---|---|---|
| **배치 = 미로 설계** | 정해진 길이 없다. 모든 건물이 길을 막으므로 배치가 곧 적의 경로가 된다. 길게 돌리면 방어가 쉬워지고, 일부러 짧게 열어 영웅이 싸울 "킬존"을 만들 수도 있다. | ✅ 흐름장(BFS) 길찾기, 완전 봉쇄 금지, 설치 전 **새 경로 미리보기 + 경로 길이 증감 표시** |
| **직접 싸우는 영웅** | 영웅은 타워 사이를 누비며 싸운다. 타워는 영웅에게도 벽이다 → 미로 설계가 영웅 동선에도 영향. | ✅ WASD/우클릭 이동, 자동 공격, 광역 스킬, 타워 충돌, 접촉 피해·사망/부활 |
| **드랍으로 성장** | 적이 확률적으로 아이템을 떨어뜨린다. 주우러 가야 한다 → "안전한 곳에 있을까 vs 위험을 무릅쓰고 주울까" 긴장. | ✅ 골드/회복약/유물 드랍, 12초 후 소멸(깜빡임 경고), 자석 범위 |
| **매 런이 다르다** | 로그라이크: 랜덤 맵(바위 배치), 랜덤 유물 선택, 죽으면 처음부터. | ✅ 랜덤 바위, 웨이브 클리어마다 유물 3택1, 최고 기록 저장 |

## 3. 코어 루프

```
[건설 페이즈] 미로 설계·타워 강화
      ↓ 웨이브 시작
[전투 페이즈] 타워 자동 공격 + 영웅 조작, 드랍 줍기 (전투 중에도 건설 가능)
      ↓ 웨이브 클리어
[보상] 골드 + 유물 3택1 (또는 골드로 건너뛰기)
      ↓ 반복 (5웨이브마다 보스, 20웨이브 클리어 시 승리)
[런 종료] 기록 → (향후) 메타 성장 → 새 런
```

## 4. 시스템 상세 (현재 수치는 `src/config.js`)

### 4.1 맵 / 경로
- 22×13 격자, 왼쪽 입구 → 오른쪽 기지.
- 적은 목표에서 역방향 BFS로 만든 거리장을 따라 이동. 건설/판매 즉시 모든 적이 경로를 다시 계산.
- 설치 불가 조건: 입구·기지·바위·기존 건물, 영웅/적이 서 있는 칸, **길을 완전히 막는 칸**, 적을 고립시키는 칸.

### 4.2 건물
| 이름 | 비용 | 역할 |
|---|---|---|
| 벽 | 5 | 공격 없음. 저렴한 미로 재료 |
| 화살탑 | 30 | 빠른 단일 공격 |
| 대포탑 | 50 | 느린 범위 공격 |
| 냉기탑 | 40 | 둔화 |

- 강화 최대 Lv.3 (피해 +60%/Lv, 사거리 +0.35칸/Lv, 공속 +10%/Lv). 판매 시 투자금 70% 환급.
- 타워는 "목표에 가장 가까운 적"을 우선 공격.

### 4.3 영웅
- HP 100, 자동 공격(사거리 내 가장 가까운 적), 스킬 **회오리**(Space, 광역 3배 피해, 쿨 6초).
- 적과 닿으면 초당 피해. 사망 시 5초 후 기지에서 부활 (런 종료 조건은 아님 → 부담 없이 과감하게).

### 4.4 적
| 이름 | 특징 | 등장 |
|---|---|---|
| 졸병 | 기본 | 1~ |
| 날쌘이 | 빠르고 약함 | 3~ |
| 덩치 | 느리고 단단함, 기지 피해 2 | 4~ |
| 보스 | 5웨이브마다, 유물 확정 드랍, 기지 피해 5 | 5,10,15,20 |

### 4.5 아이템 / 유물
- 드랍률 18%(유물로 증가 가능): 골드 55% / 회복약 30% / 유물 15%.
- 유물 17종 (영웅 강화, 타워 강화, 경제, 유틸). 중복 획득 시 효과 중첩.
- 획득 경로: 필드 드랍, 보스, 웨이브 보상 3택1.

## 5. 다음 단계 아이디어 (우선순위순)

1. **플레이테스트 & 밸런스**: 경로 길이 vs 난이도, 영웅 비중이 너무 크거나 작지 않은지.
2. **비행 적**: 미로를 무시 → "미로만 짜면 끝"을 방지하고 영웅의 역할을 강화.
3. **영웅 선택 / 액티브 아이템**: 근접형·원거리형·소환형 등, 액티브 아이템 슬롯(폭탄, 임시 벽 등).
4. **맵 이벤트 노드**: 웨이브 사이에 상점 / 이벤트 / 엘리트 선택(슬레이 더 스파이어식 분기).
5. **메타 성장**: 런 종료 시 재화 → 영웅·유물 풀 해금 (영구 스탯 상승은 최소화).
6. **모바일 조작**: 탭=건설, 영웅은 가상 조이스틱 또는 탭 이동(우클릭 이동이 이미 이 구조).
7. **테마 확정 후 아트/사운드**.

## 6. 수익 모델 검토

### 선택지 비교

| 모델 | 장점 | 단점 | 어울리는 플랫폼 |
|---|---|---|---|
| **A. 유료 $2.99 (프리미엄)** | 구현 단순, 밸런스가 순수함, 로그라이크 유저층이 선호, 리뷰에 유리 | 모바일에서는 다운로드 장벽이 매우 큼, 출시 후 추가 수익 없음 | **PC(Steam)**, Switch |
| **B. 무료 + 광고 + 광고제거 IAP** | 모바일 유입 최대, 광고제거($2.99~3.99)가 사실상 "유료판" 역할 | 광고 SDK/정책/개인정보 대응, 강제 광고는 리뷰 악화 | 모바일 |
| **C. 무료 + 아이템 판매** | 매출 상한이 높음 | **로그라이크와 충돌**: 파워 아이템을 팔면 "런의 공정함"이 깨지고 밸런스를 과금 중심으로 짜게 됨. 1인/소규모 개발에 운영 부담 큼 | 모바일 (라이브 운영 전제) |

### 추천

- **Steam(PC)부터 낸다면 → A. 유료 $2.99~4.99.** 이 장르(로그라이크 TD) 유저는 유료 구매에 익숙하고, 과금 요소가 없다는 것 자체가 셀링 포인트. 데모 공개 → 위시리스트 확보가 정석.
- **모바일이라면 → B의 변형**: 무료 + **보상형 광고만**(강제 광고 X) + **"프리미엄 팩" 1회 결제 $2.99** (광고 제거 + 보상형 광고 혜택 상시 적용 + 추가 영웅 1종).
- **C(파워 아이템 판매)는 비추천.** 팔고 싶다면 **코스메틱(영웅/타워 스킨)**이나 **콘텐츠 확장(새 영웅·새 맵 DLC)** 형태로.

### 지금 설계에 미리 넣어두면 좋은 "과금 훅" (어느 모델이든 재사용 가능)
- 보상 선택 **리롤**(유료판: 런당 1회 무료 / 모바일: 보상형 광고)
- 기지 함락 시 **1회 부활**
- 런 종료 보상 **2배**
→ 게임 로직에서는 "런당 N회 가능한 행동"으로만 만들어 두고, 그 N을 어떻게 얻는지는 플랫폼별로 결정.

## 7. 기술 메모
- 현재: 순수 HTML5 Canvas + JS, 빌드 없음. 아이디어 검증용.
- 본 개발 시 후보: **Godot**(PC+모바일 무료, 2D에 강함) 또는 **Unity**(광고/IAP SDK 생태계). 웹 기반을 유지한다면 Phaser + Capacitor로 모바일 패키징도 가능.
